# milyfe-miforge

MiForge OS. See **README-LOCAL.md** for the full local Docker Compose
development environment (Caddy + Postgres 16 + MariaDB 11 + NocoDB,
Nextcloud, Vaultwarden, Invoice Ninja, n8n, Uptime Kuma, ntfy, Chatwoot,
Formbricks, mock backup) — run it with 3 commands and open every app in your
browser on localhost.
